01 Requisitos atendidos

Escopo entregue e verificado no backend em produção (/api/documentation).

Autenticação & autorização auth

  • JWT via guard api: register, login, me, logout (access token)
  • Perfis por enum UserType: admin, usuario, facilitador, empresa
  • Gate por perfil (middleware type): users/logs só admin; domínio para admin + usuário; setores para admin + empresa
  • Ownership: usuário empresa (vinculado a uma empresa) só vê/gerencia os setores da própria empresa
  • users.id em UUID (v7); demais tabelas em bigint
  • Senha com hash bcrypt; nunca retornada

Entidades & CRUD 8 recursos

  • CRUD RESTful: Users, Companies, Sectors, Workshops, CheckIns, Assessments, Diaries, DiaryEvidences
  • Validação isolada em FormRequest (Store/Update parcial)
  • Regras de negócio: Diary 1:1 com workshop; CPF único por workshop; score 0–10; setor único por empresa; criador = usuário autenticado
  • Setor no check-in via sector_id (opcional; null = "sem setor"), validado contra a empresa do workshop; texto livre sector mantido (retrocompatível)
  • Integridade referencial: FK bloqueia remoção → 409; referência inexistente → 422; setor em cascade com a empresa
  • Listagens paginadas com filtros

Participantes (público) sem login

  • POST /api/public/check-ins — auto check-in do participante
  • POST /api/public/assessments — avaliação anônima
  • throttle:60,1 contra abuso
  • Consentimento LGPD registrado com timestamp (lgpd_consent_at)

Auditoria (Logs) automática

  • Middleware AuditLog grava toda ação (POST/PUT/PATCH/DELETE) bem-sucedida em /api/*
  • Registra usuário, método, rota e status — gravação no terminate (sem latência)
  • Consulta admin somente-leitura: GET /api/logs paginada (per_page)

API, docs & robustez openapi

  • Swagger/OpenAPI gerado (l5-swagger) em /api/documentation
  • ForceJsonResponse: erros sempre em JSON com status correto (401/403/404/422)
  • trustProxies: URLs HTTPS corretas atrás de Apache/Cloudflare
  • Respostas consistentes sob a chave data

Qualidade & entrega devops

  • 86 testes (PHPUnit) — caminho feliz, autorização, validação, regras
  • Laravel Pint (formatação) + hooks de projeto
  • Docker dev + prod; CI no GitHub Actions
  • Deploy automático: push em homolog → VPS (rsync + compose via SSH)
  • Produção no ar: https://mentis.kassiosousa.com.br; seeder de admin
